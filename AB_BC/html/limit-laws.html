Limit Laws 极限定律

Each law includes a collapsible epsilon-delta proof / 每条都有可收起的 ε-δ 证明。

Let \(c\) and \(k\) be real numbers, and suppose \(\displaystyle \lim_{x\to c} f(x)=A\) and \(\displaystyle \lim_{x\to c} g(x)=B\) exist.

Under these assumptions, the following limit laws are valid. 在这些前提下，下面的极限定律成立。

Teaching note 教学提示 The product law requires both factor limits to exist. However, a product limit may still exist even when one factor has no limit; see the example under part b). 乘法律的使用前提是两个因子的极限都存在；但某个因子极限不存在时，乘积极限仍然可能存在。
a
\[ \lim_{x\to c}\big(f(x)\pm g(x)\big) = \lim_{x\to c}f(x)\pm\lim_{x\to c}g(x) = A\pm B \]
Sum / difference law
Epsilon-delta proof / ε-δ 证明 ⌄

For any \(\varepsilon>0\), use the definitions of \(\lim f=A\) and \(\lim g=B\).

  1. Choose \(\delta_1\) so that \(0<|x-c|<\delta_1\Rightarrow |f(x)-A|<\varepsilon/2\).
  2. Choose \(\delta_2\) so that \(0<|x-c|<\delta_2\Rightarrow |g(x)-B|<\varepsilon/2\).
  3. Let \(\delta=\min(\delta_1,\delta_2)\). Then \[ |(f(x)\pm g(x))-(A\pm B)| \le |f(x)-A|+|g(x)-B| <\varepsilon. \]
b
\[ \lim_{x\to c}\big(f(x)g(x)\big) = \left(\lim_{x\to c}f(x)\right) \left(\lim_{x\to c}g(x)\right) = AB \]
Product law
Epsilon-delta proof / ε-δ 证明 ⌄

The useful trick is to add and subtract \(Ag(x)\):

\[ |f(x)g(x)-AB| = |g(x)(f(x)-A)+A(g(x)-B)|. \]
  1. First choose \(\delta_0\) so that \(|g(x)-B|<1\), hence \(|g(x)|\le |B|+1\).
  2. Choose \(\delta_1\) so that \(|f(x)-A|<\dfrac{\varepsilon}{2(|B|+1)}\).
  3. Choose \(\delta_2\) so that \(|g(x)-B|<\dfrac{\varepsilon}{2(|A|+1)}\).
  4. For \(\delta=\min(\delta_0,\delta_1,\delta_2)\), \[ |f(x)g(x)-AB| \le |g(x)||f(x)-A|+|A||g(x)-B| <\varepsilon. \]
What is \(\displaystyle \lim_{x\to0} x^2\sin\frac1x\)? / 思考题 ⌄

This example is placed under the product law because it shows an important warning: the product law needs both individual limits to exist, but a product limit can still exist even when one factor limit does not exist.

Squeeze Theorem / 夹逼定理

If \(m(x)\le h(x)\le M(x)\) for all \(x\) close to \(c\), except possibly at \(c\), and \[ \lim_{x\to c}m(x)=\lim_{x\to c}M(x)=L, \] then \(\displaystyle \lim_{x\to c}h(x)=L\).

One factor limit DNE

\[ \lim_{x\to0}\sin\frac1x \text{ DNE.} \]

As \(x\to0\), \(\sin(1/x)\) oscillates between \(-1\) and \(1\) infinitely often.

The product limit exists

\[ -1\le \sin\frac1x\le 1 \quad\Rightarrow\quad -x^2\le x^2\sin\frac1x\le x^2. \]

Since \(\lim_{x\to0}(-x^2)=0\) and \(\lim_{x\to0}x^2=0\), the squeeze theorem gives \[ \lim_{x\to0}x^2\sin\frac1x=0. \]

c
\[ \lim_{x\to c} kf(x) = k\lim_{x\to c}f(x) = kA \]
Constant multiple law
Epsilon-delta proof / ε-δ 证明 ⌄

If \(k=0\), then \(kf(x)=0\), so the limit is immediate. If \(k\ne0\):

  1. Given \(\varepsilon>0\), choose \(\delta\) so that \(0<|x-c|<\delta\Rightarrow |f(x)-A|<\varepsilon/|k|\).
  2. Then \[ |kf(x)-kA|=|k|\,|f(x)-A|<\varepsilon. \]
d
\[ \lim_{x\to c}\frac{f(x)}{g(x)} = \frac{\lim_{x\to c}f(x)}{\lim_{x\to c}g(x)} = \frac{A}{B}, \quad B\ne0 \]
Quotient law
Epsilon-delta proof / ε-δ 证明 ⌄

First prove the reciprocal law for \(g\). Since \(B\ne0\), keep \(g(x)\) away from \(0\).

  1. Choose \(\delta_0\) so that \(|g(x)-B|<|B|/2\). Then \(|g(x)|>|B|/2\).
  2. For such \(x\), \[ \left|\frac1{g(x)}-\frac1B\right| = \frac{|g(x)-B|}{|g(x)||B|} \le \frac{2|g(x)-B|}{|B|^2}. \]
  3. Thus \(\lim_{x\to c}1/g(x)=1/B\). Apply the product law to \(f(x)\cdot 1/g(x)\).
e
\[ \lim_{x\to c}\big(f(x)\big)^n = \left(\lim_{x\to c}f(x)\right)^n = A^n \]
Power law, \(n\in\mathbb N\)
Epsilon-delta proof / ε-δ 证明 ⌄

Use induction from the product law.

  1. For \(n=1\), the result is exactly \(\lim f=A\).
  2. If \(\lim (f(x))^n=A^n\), then \[ \lim (f(x))^{n+1} = \lim\big((f(x))^n f(x)\big) = A^n\cdot A = A^{n+1}. \]
  3. Therefore the law holds for every positive integer \(n\).
f
\[ \text{If }\lim_{x\to c}g(x)=L \text{ and }\lim_{u\to L}f(u)=f(L), \text{ then } \lim_{x\to c}f(g(x))=f(L). \]
Composition law
Epsilon-delta proof / ε-δ 证明 ⌄

Use the epsilon-delta definition twice, passing the output of \(g\) into \(f\).

  1. Given \(\varepsilon>0\), since \(\lim_{u\to L} f(u)=f(L)\), choose \(\eta>0\) so that \(|u-L|<\eta\Rightarrow |f(u)-f(L)|<\varepsilon\).
  2. Since \(\lim_{x\to c}g(x)=L\), choose \(\delta>0\) so that \(0<|x-c|<\delta\Rightarrow |g(x)-L|<\eta\).
  3. Let \(u=g(x)\). Then \[ |f(g(x))-f(L)|<\varepsilon, \] so \(\lim_{x\to c}f(g(x))=f(L)\).
